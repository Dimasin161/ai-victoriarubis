## 2026-11-10

### Репозиторий пока остаётся публичным
Решение Димы: `Dimasin161/ai-victoriarubis` оставляем открытым, закроем позже.

Почему нельзя просто закрыть: репозиторий — форк публичного
`rubisvika123-png/ai-victoriarubis`, а GitHub не разрешает менять видимость
форка (она наследуется от upstream). Проверено: `PATCH /repos/... {"private":true}`
→ 403, плюс документация GitHub "About permissions and visibility of forks".

Путь, когда дойдут руки:
1. Дима создаёт пустой private-репозиторий (токен не может: PAT ограничен
   одним репозиторием, прав Administration нет).
2. Добавляет его в список репозиториев токена.
3. Переносим историю (`git push --mirror`), работаем там.
4. Старый форк удаляем только по явному "да" Димы.

Остаётся в силе: upstream-оригинал всё равно публичный, его закрыть нельзя.
Секретов в индексе нет (проверено 2026-11-10).

### Токену выданы права на запись
Fine-grained PAT: режим Only select repositories → `ai-victoriarubis`,
Contents = Read and write, Pull requests = Read and write, Metadata = Read-only.
До этого стоял режим Public repositories (read-only) — отсюда были 403 на push.

## 11.11.2026 — общая память команды (second brain)
- Папка: /root/second-brain (не /root/gbrain) — именно её ночной бэкап
  /root/.agents-backup/backup.sh копирует по умолчанию (блок "Shared team folder",
  ~/second-brain), значит память попадает в копию без правки крона.
- Формат: memory.md, один факт = одна строка «- дата · метка автора · факт».
  Запись только через bin/gbrain (flock от одновременной записи двух агентов,
  журнал в log/gbrain.log). Метка автора: --who > $GBRAIN_WHO > agents.tsv по
  папке агента > «неизвестный».
- Чтение сделано хуком SessionStart (gbrain-session-context): факты сами
  попадают в контекст обоих агентов при старте — не надеюсь на то, что агент
  вспомнит сходить в файл.
- Запись подстрахована Stop-хуком require-gbrain-write.py (копия приёма из
  require-telegram-reply.js): сказали «запомни:»/«забудь:», а в общую память
  не записали — ход разворачивается. Заглушки вида «запомни: <факт>» в
  объяснениях за приказ не считаются.
- Хуки прописаны в ОБЩИХ настройках ~/.claude/settings.json, а не в
  plugin/.claude/settings.json: один файл на обоих агентов и не трогаю
  отслеживаемые git-файлы во втором клоне репозитория.
